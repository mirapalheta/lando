# Code of Conduct

## Our standards

This is a small, focused open-source project. Participation is welcome from
anyone who engages respectfully and in good faith.

Expected behaviour:

- Be direct and constructive in code review and issue discussion.
- Assume good intent; ask for clarification before assuming bad faith.
- Keep discussion on-topic — this repo is about the bridge, not broader debates.
- Accept maintainer decisions gracefully, even when they go against your
  preference.

Behaviour that is not welcome:

- Personal attacks or sustained hostile tone toward any contributor.
- Spam, off-topic promotion, or drive-by negativity with no actionable content.

## Enforcement

Issues that violate these standards can be reported to the maintainer via the
[private Security Advisory channel](https://github.com/mirapalheta/lando/security)
(or by email if listed on the profile). Reports will be handled discreetly.

The maintainer reserves the right to close issues, remove comments, or block
accounts that repeatedly violate these standards.

## Scope

These standards apply in all project spaces: issues, pull requests, discussions,
and any other forum where project business is conducted.
